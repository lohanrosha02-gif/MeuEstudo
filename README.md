# Meu estudo | PMPE 2026

Site de estudos em HTML, CSS e JavaScript. O aplicativo está reunido em **index.html**, na raiz do repositório.

## Abrir
- Localmente: abra `index.html` no navegador ou com Live Server.
- Online, após ativar GitHub Pages: https://lohanrosha02-gif.github.io/MeuEstudo/

## Ativar GitHub Pages
1. Abra **Settings > Pages** neste repositório.
2. Em **Build and deployment**, selecione **Deploy from a branch**.
3. Em **Branch**, escolha `main` e `/(root)`, depois clique em **Save**.
4. Quando o GitHub Pages apresentar o link de publicação, abra-o.

## Incluído na versão pública
- Teoria e revisão de 135 assuntos de 6 matérias.
- Banco de 1.350 exercícios de fixação autorais.
- Progresso no navegador e interface responsiva.

## Limites e direitos
Este é um projeto independente e não tem vínculo oficial com a PMPE. Os arquivos originais enviados (PDFs e outras mídias), e as questões extraídas automaticamente deles, não fazem parte da versão pública para evitar a republicação indevida de materiais de terceiros. As respostas dos exercícios autorais não foram verificadas individualmente.


## Recompensas e personalização

O site inclui moedas **virtuais**, sem compras reais. Use o botão **✦ Loja** no topo para trocar moedas por temas, emblemas e molduras.

### Como conseguir moedas
- +5 por acertar uma questão nova de um assunto (apenas uma recompensa por questão).
- +10 pelo primeiro acerto do dia.
- +20 ao acumular cinco novos acertos no mesmo dia.
- +10 por marcar todas as fichas de teoria de um assunto como lidas (uma vez por assunto).
- +15 por marcar um assunto como concluído (uma vez por assunto).
- +25 por concluir as 10 questões com pelo menos 70% de acertos (uma vez por assunto).

A loja oferece temas Lilás, Oceano, Menta, Amanhecer e Noite, além de emblemas e molduras para o perfil. O progresso anterior dos assuntos não é apagado.

**Observação:** moedas, itens, personalizações e progresso são salvos apenas no `localStorage` do navegador/dispositivo. Não há sincronização entre dispositivos, pagamentos ou transferência de moedas. Limpar os dados do navegador pode apagar o saldo e as compras. Para executar offline, `recompensas.css` e `recompensas.js` precisam estar ao lado de `index.html`.
